## 🛠️ How to Use

1. Navigate to the Step → Lecture → Problem file
2. Each `.cpp` file has a template with sections for:
   - Problem description
   - Approach
   - Time & Space Complexity
   - Solution code
3. Write your solution inside `main()` and compile with:
   ```bash
   g++ -o solution filename.cpp
   ./solution
   ```
